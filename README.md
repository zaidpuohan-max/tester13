# Portofolio M. Fathan Zaaid Pohan

Situs portofolio pribadi berbahasa Indonesia, dibuat dengan HTML, CSS, dan JavaScript tanpa proses build, dependensi, atau koneksi internet.

## Cara membuka

1. Buka folder `portofolio-fathan`.
2. Klik dua kali `index.html` atau buka file tersebut melalui peramban.

## Foto

Semua foto disimpan di folder yang sama dengan `index.html` dan dirujuk memakai nama file relatif agar cocok dengan susunan repositori GitHub Pages (`/tester11/`). Pertahankan kelima berkas JPEG di folder yang sama dengan `index.html` saat mengunggah situs.
